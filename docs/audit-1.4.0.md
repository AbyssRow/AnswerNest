# 1.4.0 配置迁移验证

日期：2026-10-25。目标是在 Windows 导出一次配置，在 Mac 导入后恢复模型和搜索设置，避免重新输入密钥和参数。

## 功能范围

「设置 → 常规设置」新增「配置导入导出」。导出一个带格式标识和版本号的 JSON 文件；导入先校验并预览平台、模型数量，确认后保存。

包含平台 API Key、地址、代理、自定义请求头、模型参数、自定义协议代码、答题／总结模型选择、各搜索服务的独立连接配置，以及常规设置。文件含明文密钥，界面和 README 均有明确说明。

不迁移题库数据、窗口大小／位置、题库保存文件夹及其数据库 ID，保留目标电脑上的值。网络绑定地址按导入的局域网开关重新计算。导入后正在运行的题库服务需要停止并重新启动，以使用新的监听配置。

导入前等待启动时的文件恢复完成。确认导入后显式等待常规和模型配置写入磁盘，即使导入配置关闭了自动保存也会完成本次保存。写入失败时恢复之前的配置；若恢复写入本身也失败，会明确提示磁盘未能全部恢复，避免报告成功。

## 实际桌面程序验证

使用 release 程序、隔离的数据目录及本地模拟模型服务验证以下 8 组场景，无页面脚本异常：

1. 导出完整配置，使用实际原生文件写入保存 JSON；保存对话框的文件路径由测试替身提供。
2. 取消保存对话框，不显示导出成功、不改写已有文件。
3. 模拟导出文件写入失败，明确提示失败。
4. 选择无效 JSON，拒绝导入且不改变已有常规和模型配置。
5. 正确预览平台和模型数量；取消导入不改变配置。
6. 成功导入后，两份磁盘配置都更新，主题立即生效，目标机器题库文件夹和窗口位置保持原值。
7. 模拟常规配置写入失败，模型和常规配置均恢复，并显示失败提示。
8. 重载 WebView 后，平台、模型选择和密钥仍保留，并通过实际桌面 HTTP 题库接口，使用导入的新 Key 成功请求本地模拟模型。

另有 9 组已有桌面场景通过，覆盖配置迁移、题目编辑、服务启动停止、OCS 5.2.3 实际 wrapper handler、Base64 图片、分歧总结、缓存命中、题库切换竞态、日志恢复和模型缓存损坏恢复。合计 17 组场景通过。

本次未使用真实付费 API Key，未在 macOS 实机运行；配置格式和文件选择逻辑跨平台共用，Mac 仍需自行构建和验证。项目代码索引连接不可用，本次结构核对采用源码与调用点检索。构建保留已有的大分块、bundle identifier 及 Tauri bundler 类型标记警告。
